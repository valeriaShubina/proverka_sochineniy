[ROLE]
Ты — Senior Python Developer, специалист по обработке русского языка и созданию линтеров.

[REQUIREMENTS]
1. Создай модуль spellchecker.py с функцией check_spelling(text: str) -> List[Dict]
2. Функция принимает строку текста на русском языке
3. Возвращает список найденных орфографических ошибок
4. Каждая ошибка содержит:
   - word (str): ошибочное слово
   - position (int): индекс начала слова в тексте
   - suggestions (List[str]): список исправлений (максимум 3)
5. Если ошибок нет, возвращается пустой список
6. Используй встроенный словарь русских слов (без внешних API)

[ENTITIES]
- text: str — входной текст
- error: Dict — {"word": str, "position": int, "suggestions": List[str]}
- return: List[error]

[APPROACH]
- Разбить текст на слова с учётом пунктуации
- Для каждого слова проверить наличие в словаре
- Если слова нет — считать ошибкой
- Для исправлений использовать расстояние Левенштейна (Levenshtein distance)
- Брать ближайшие по расстоянию слова из словаря

[STRUCTURE]
- Файл: spellchecker.py
- Функция: check_spelling(text: str) -> List[Dict]
- Вспомогательная: _levenshtein_distance(a: str, b: str) -> int
- Вспомогательная: _get_suggestions(word: str, dictionary: set, max_suggestions: int = 3) -> List[str]
- Словарь: _load_dictionary() -> set (встроенный минимальный набор из 1000 слов)

[OPERATIONS]
1. Очистить текст (lowercase для сравнения, но сохранить оригинал для вывода)
2. Найти границы слов (регулярное выражение r'[а-яё]+')
3. Для каждого найденного слова:
   a. Если слово в словаре → пропустить
   b. Если не в словаре → найти 3 ближайших слова из словаря по Левенштейну
   c. Добавить в результат
4. Вернуть список ошибок

[NORMS]
- PEP 8
- Аннотации типов (from typing import List, Dict)
- Докстринги для всех функций
- Кодировка UTF-8

[SAFEGUARDS]
- Если текст пустой → вернуть []
- Если слово состоит из цифр → не считать ошибкой
- Если слово уже в нижнем регистре → не менять
- Не использовать внешние библиотеки (только стандартные: re, typing, itertools)
- Запрещено: requests, pymorphy2, language_tool_python
